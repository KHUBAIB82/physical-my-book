# Module 1: The Robotic Nervous System (ROS 2)

ROS 2 works like the nervous system of a robot.

It connects sensors, AI brains, and motors together.

## Key Concepts
- Nodes: small programs running inside the robot
- Topics: communication channels
- Services and Actions: request–response systems

ROS 2 allows Python AI agents to control humanoid robots.
